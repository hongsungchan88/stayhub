# 퍼블리싱 폴더

정적 화면(HTML/CSS) 작업 폴더입니다.

서버 로직이나 데이터 연동 없이, 화면의 마크업과 스타일만 먼저 만들어 확인하는 공간입니다.
여기서 확정된 화면이 이후 실제 개발에 그대로 넘어갑니다.

## 파일명 규칙

화면 ID를 기준으로 이름을 정합니다.

```
scr-{업무영역}-{번호}-{화면명}.html
```

예시

- `scr-acc-01-login.html`
- `scr-acc-02-signup.html`
- `scr-rsv-01-list.html`

번호는 두 자리(`01`, `02`, ...)로 맞추고, 화면명은 영문 소문자와 하이픈만 사용합니다.

## CSS 규칙

**`common.css` 한 벌을 모든 화면이 공유합니다.**

- 화면마다 별도의 CSS 파일을 만들지 않습니다.
- 공통 스타일(색상, 폰트, 버튼, 폼, 레이아웃)은 모두 `common.css`에 모읍니다.
- 각 HTML에서는 아래 한 줄로만 불러옵니다.

```html
<link rel="stylesheet" href="common.css">
```

- 특정 화면에만 필요한 스타일은 `common.css` 안에서 화면 단위 클래스로 구분해 작성합니다.
