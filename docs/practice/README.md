# 연습용 문서 폴더

팀원들이 **첫 PR을 연습하는 자리**입니다.

실제 프로젝트 산출물이 아니라, Git·GitHub 흐름(브랜치 생성 → 커밋 → push → PR 생성 → 리뷰 → 머지)을
부담 없이 익혀보기 위한 공간입니다. 여기에 올린 파일은 서비스 코드에 아무 영향을 주지 않으니
마음 편히 연습하세요.

## 파일명 규칙

```
연습-본인이름.md
```

예시

- `연습-홍길동.md`
- `연습-김철수.md`

한 사람당 파일 하나를 사용합니다. 다른 사람의 파일은 수정하지 않습니다.

## 연습 순서

1. 이 저장소를 clone 합니다.
2. 새 브랜치를 만듭니다. 팀 규칙대로 하이픈만 사용합니다. (예: `practice-hong`)
3. `docs/practice/연습-본인이름.md` 파일을 만들고 자유롭게 자기소개나 메모를 씁니다.
4. 커밋하고 push 합니다.
5. GitHub에서 `main` 브랜치로 향하는 Pull Request를 만듭니다.
6. 리뷰를 받은 뒤 머지합니다.

> 브랜치 이름에 슬래시(`/`)는 쓰지 않습니다. 팀 규칙은 하이픈 방식(`feature-{코드}-{작업명}`)이고,
> 연습 브랜치도 같은 방식(`practice-{이름}`)으로 맞춥니다.
