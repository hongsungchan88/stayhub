# <stayhub>

호텔 CMS(웹사이트 콘텐츠 관리) + PMS(객실·예약 관리) 통합 관리 시스템

- **기간** 2026.09 ~ 12 (개발 마감 11월 말)
- **팀** 5명 · 창업 동아리 팀 프로젝트
- **정기 회의** 매주 화요일 30분 (제출물은 전날 월요일까지)

## 담당

| 담당 | 영역 | 브랜치 코드 |
|---|---|---|
| 팀원 A | 계정·통계·시스템 | `acc` `sta` `sys` |
| 팀원 B | 예약·채널 | `rsv` `chn` |
| 팀원 C | 객실·결제 | `rom` `pay` |
| 팀원 D | 화면 퍼블리싱 | `pub` |
| 총괄 | 콘텐츠·커뮤니케이션 | `cms` `com` |
